# Thread & Loom — Apparel & Textiles E-Commerce Website

A beginner-friendly front-end demonstration of an apparel and textiles online store. Built with HTML, CSS, and JavaScript.

## Features
- Responsive storefront layout for desktop and mobile
- Product cards with sample prices and fabric details
- Product search and category filtering
- Shopping cart with quantity updates and item removal
- Cart total calculated in Indian rupees
- Demo checkout message (no real payment)
- Newsletter form demo (does not collect or send data)

## How to run
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Search for products, filter categories, and try the shopping cart.

## Project files
- `index.html` — page structure and content
- `style.css` — layout, colors, and responsive styling
- `script.js` — product search, filters, and shopping cart logic

## Limitations
This is a front-end student project. It does not include a server, database, user accounts, real inventory, order storage, or payment processing. Do not enter real payment details. A production store would need a secure backend, database, authentication, server-side validation, and a trusted payment provider.
